# MathPulse — Cursor Rules
# Файл: .cursorrules (корень проекта)
# Cursor читает этот файл при каждом запросе. Все правила действуют всегда.

## Проект

MathPulse — интерактивная образовательная платформа по высшей математике.
Стек: Vite 5 + React 18 + TypeScript + Tailwind CSS v3 + shadcn/ui + framer-motion + lucide-react.
Математика: KaTeX через CDN. Графики: только SVG/JSX, canvas запрещён.
Деплой: Vercel, push to main.

---

## КРИТИЧЕСКИЕ ПРАВИЛА — нарушение недопустимо

1. **Никаких hex-цветов и Tailwind palette-утилит в TSX.**
   Запрещено: `#fff`, `text-blue-500`, `bg-gray-900`.
   Разрешено: только семантические токены (`text-primary`, `bg-card/60`, `text-muted-foreground`).
   Исключение: `COLOR_MAP` в файлах уроков — там Tailwind-цвета для 4 акцентов допустимы (см. паттерн ниже).

2. **Никогда `canvas ctx.roundRect()`.**
   Закруглённые углы только через SVG `<rect rx="8" ry="8" />`.

3. **Никогда `useState` для флагов внутри RAF-анимаций.**
   Переключатели (show/hide, toggle), которые читаются внутри `requestAnimationFrame`, — только `useRef`.
   ```tsx
   // WRONG
   const [showLimit, setShowLimit] = useState(true);
   // в RAF-колбэке showLimit будет устаревшим (stale closure)

   // CORRECT
   const showLimitRef = useRef(true);
   useEffect(() => { showLimitRef.current = showLimit; }, [showLimit]);
   // в RAF читаем showLimitRef.current
   ```

4. **Никогда markdown-математику.** Запрещено: `` $x^2$ ``, `` $$\int$$ `` в .tsx файлах.
   Только компонент `<Math>` с KaTeX (реализация ниже).

5. **Каждый урок — три обязательных слоя в intro-секции** (Hero card + TldrBox + KEY_FINDINGS grid).
   Пропустить нельзя.

6. **Каждый урок содержит `<CompleteButton>` и completion card.** Шаблон ниже.

7. **Контент страницы урока — только диспатч в sub-компоненты.**
   Файл `src/pages/LessonX_Y.tsx` содержит скаффолд и `{s.id === "foo" ? <FooSection /> : ...}`.
   Никакого инлайн-контента.

8. **Все маршруты — lazy-loaded, добавлять выше `path="*"`** в `src/App.tsx`.

## Компонент <Math> — полная реализация

Файл: `src/components/math/Math.tsx`

```tsx
import { useEffect, useRef } from "react";

declare global { interface Window { katex: any } }

let katexLoaded = false;
const loadKatex = (): Promise<void> => {
  if (katexLoaded) return Promise.resolve();
  return new Promise((resolve) => {
    const link = document.createElement("link");
    link.rel = "stylesheet";
    link.href = "https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.css";
    document.head.appendChild(link);
    const script = document.createElement("script");
    script.src = "https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.js";
    script.onload = () => { katexLoaded = true; resolve(); };
    document.head.appendChild(script);
  });
};

export function Math({ children, display = false }: { children: string; display?: boolean }) {
  const ref = useRef<HTMLSpanElement>(null);
  useEffect(() => {
    loadKatex().then(() => {
      if (ref.current && window.katex) {
        window.katex.render(children, ref.current, {
          displayMode: display,
          throwOnError: false,
          trust: true,
        });
      }
    });
  }, [children, display]);
  return <span ref={ref} className={display ? "block text-center my-4" : "inline"} />;
}
```

Использование:
```tsx
<Math>{"x^2 + y^2 = r^2"}</Math>                                        // inline
<Math display>{"\\int_{-\\infty}^{\\infty} e^{-x^2}\\,dx = \\sqrt{\\pi}"}</Math>  // блочная
```

## Компонент <DerivationBlock>

Файл: `src/components/math/DerivationBlock.tsx`

Интерфейс:
```tsx
interface DerivationStep {
  formula: string;        // LaTeX строка
  explanation: string;    // текстовое пояснение
  isResult?: boolean;     // true → cyan-рамка «итог»
}
interface DerivationBlockProps {
  title: string;
  steps: DerivationStep[];
  initiallyOpen?: boolean;
}
```

Визуальные правила при реализации:
- Заголовок: иконка `<FlaskConical>` + метка `"ВЫВОД"` классом `text-xs uppercase tracking-widest text-muted-foreground font-['Orbitron']`
- Каждый шаг: `border-l-2 border-cyan-500/40 pl-4`; формула через `<Math display>`; пояснение `text-sm leading-relaxed text-muted-foreground`
- Шаг с `isResult: true`: `border-l-2 border-cyan-400 bg-cyan-500/5 rounded-r-lg px-4 py-3`
- Кнопки управления: `variant="ghost" size="sm"` с `className="text-cyan-400 hover:text-cyan-300"`
- Анимация разворачивания шагов: `<motion.div>` с `initial={{ opacity:0, height:0 }}` → `animate={{ opacity:1, height:"auto" }}`

Использование:
```tsx
<DerivationBlock
  title="Вывод формулы Тейлора"
  steps={[
    { formula: "f(x) \\approx \\sum_{k=0}^n \\frac{f^{(k)}(a)}{k!}(x-a)^k", explanation: "Аппроксимируем полиномом степени n" },
    { formula: "R_n(x) = \\frac{f^{(n+1)}(\\xi)}{(n+1)!}(x-a)^{n+1}", explanation: "Остаточный член в форме Лагранжа", isResult: true },
  ]}
/>
```

## Компонент CompleteButton — универсальный

Файл: `src/components/CompleteButton.tsx`

```tsx
import { useState, useEffect } from "react";
import { CheckCircle2 } from "lucide-react";
import { Button } from "@/components/ui/button";
import { markLessonComplete, isLessonComplete } from "@/lib/progress";

export default function CompleteButton({ lessonId }: { lessonId: string }) {
  const [done, setDone] = useState(() => isLessonComplete(lessonId));

  useEffect(() => {
    if (done) return;
    const onScroll = () => {
      const pct = (window.scrollY / (document.documentElement.scrollHeight - window.innerHeight)) * 100;
      if (pct >= 90) {
        markLessonComplete(lessonId);
        setDone(true);
        window.removeEventListener("scroll", onScroll);
      }
    };
    window.addEventListener("scroll", onScroll, { passive: true });
    return () => window.removeEventListener("scroll", onScroll);
  }, [done, lessonId]);

  return (
    <Button
      onClick={() => { markLessonComplete(lessonId); setDone(true); }}
      disabled={done}
      size="lg"
      className="w-full md:w-auto bg-gradient-to-r from-cyan-500 via-purple-500 to-pink-500
                 text-white font-semibold shadow-[0_0_24px_hsl(var(--primary)/0.45)]
                 hover:shadow-[0_0_32px_hsl(280_85%_65%/0.55)] hover:scale-[1.02]
```
