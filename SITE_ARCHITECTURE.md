# SITE_ARCHITECTURE.md — Архитектура единого портала «MathPulse»

> **Этап 2 из 7.** Проектный документ. Базируется на `MERGE_ANALYSIS.md` и решениях пользователя:
> 1) единая **светлая тема statspark**; 2) целевой проект — **host `calculus-visuals`**; 3) язык — **только русский**.

## 0. Концепция

Один цельный учебный портал по высшей математике: от понятия функции до математической статистики. Материал из 8 проектов раскладывается в **9 разделов** (курсов), каждый раздел — хаб с темами; внутри темы — слои **Теория → Интуиция/визуализация → Примеры → Практика (задачи/билеты)**, связанные кросс-ссылками без дублирования.

**Единая модель URL:** `/<раздел>` (хаб) и `/<раздел>/<тема>` (страница темы/урока). Старые URL проектов → редиректы.

## 2. Пользовательский путь (от новичка к продвинутому)

**Трек A — Базовый матанализ (новичок):**
`Функции → Пределы → Производные → Интегралы → Ряды`

**Трек B — Продвинутый матанализ:**
`Ряды → Дифференциальные уравнения` (требует производных и интегралов)

**Трек C — Линейная алгебра:**
`Линейная алгебра` (самостоятельный вход; мост к /diffeq/second-order и /statistics через SVD/PCA)

**Трек D — Вероятность и статистика:**
`Теория вероятностей → Математическая статистика` (мост из линейной алгебры: PCA → факторный анализ)

```
                 ┌─ Функции ─ Пределы ─ Производные ─ Интегралы ─ Ряды ─┐
   Старт ────────┤                                                      ├─ Дифф. уравнения
                 │                                                      │
                 ├─ Линейная алгебра ───────────────(SVD/PCA)──────────┼─→ ┐
                 │                                                          │
                 └─ Теория вероятностей ─────────────────────────────────→ Мат. статистика
```

На главной — «Рекомендованный путь» (Трек A по умолчанию) + переключатель уровней (Начальный/Средний/Продвинутый), как метки `level` в `topicMap`.

## 3. Навигация

### 3.1. Верхнее меню (Header)
* Лого «MathPulse» → `/`
* Выпадающие пункты по 9 разделам (мега-меню со списком тем) — десктоп.
* Кнопка глобального поиска (⌘K / Ctrl-K).
* Индикатор прогресса/XP.
* Мобильный бургер → выезжающая панель с аккордеоном разделов.

### 3.2. Боковая навигация (Sidebar)
* На страницах разделов/тем — слева дерево: Раздел → темы текущего раздела, активная тема подсвечена.
* Свернётся в Sheet на мобильных.
* Источник истины — `src/content/topicMap.ts` (единый, см. §4).

### 3.3. Хлебные крошки (Breadcrumbs)
`Главная → <Раздел> → <Тема>` на каждой странице темы (компонент уже есть в host: `components/lesson/Breadcrumbs.tsx`).

### 3.4. Внутренние ссылки (на странице темы)
Внизу каждой темы — блок навигации:
* **← Предыдущая тема** / **Следующая тема →** (внутри раздела; на границе раздела — переход к следующему разделу).
* **Связанные материалы** — кросс-ссылки на темы из других разделов (через `crosslinks.ts`).
* **Рекомендуется изучить далее** — следующий шаг по треку обучения.
* **Оглавление страницы (TOC)** — справа, якоря по секциям урока.

## 6. Принцип «без дублирования» (слои темы)

Для пересекающихся тем (пределы, производные, интегралы, ряды, PCA — см. §4 `MERGE_ANALYSIS.md`):

* **Хаб-тема** (страница раздела) — формальная теория и определения.
* **Интуиция/визуализация** — из host (precalc) и интерактивов (`linear_algebra_add`, charts `_-_`).
* **Практика** — задачи `probability_tasks_add` и билеты `remix-of` подключаются к темам как блок «Практика», а не как отдельный курс.
* Связь — кросс-ссылками; один и тот же текст не копируется в два места.

Пример: тема `/limits/epsilon-delta` (теория Коши из strang) ↔ `/limits/intuition` (геометрия из host) ↔ билет «Предел и непрерывность» из remix-of (блок «Практика»).

1. Подготовить единые токены темы + math-слой (react-katex) + layout.
2. Создать `content/topicMap.ts`, `crosslinks.ts`, `learningPath.ts`.

4. Для каждого: перенести компоненты/контент, адаптировать стиль, проставить маршруты, редиректы, кросс-ссылки.
5. Глобальный поиск + sitemap + TOC.
6. Этап 6 — сквозной QA.
