## 0. Резюме (TL;DR)

В рабочем пространстве находятся **8 независимых Vite + React + TS + shadcn/ui проектов**, все сгенерированы в Lovable (`"name": "vite_react_shadcn_ts"`):

| # | Проект | Расположение | Тема | Объём | Math-движок |
|---|--------|--------------|------|-------|-------------|
| 1 | **calculus-compass** (host) | `./` (корень) | Функции, пределы, непрерывность, введение в производную (Module 0–10) | ~70 страниц-уроков | custom `Math.tsx` |
| 2 | **`_-_`** | `new_materials/_-_` | Дифференциальные уравнения + Линейная алгебра (Стрэнг, 8 глав / 50 разделов) | 50 разделов + 6 графиков | react-katex |
| 3 | **strang-calculus-ru** | `new_materials/strang-calculus-ru` | Полный курс мат. анализа (Стрэнг, 16 разделов) | 16 разделов | MathJax |
| 4 | **remix-of** | `new_materials/remix-of` | Экзаменационные билеты по мат. анализу (15 билетов) | 15 билетов | MathJax |
| 5 | **linear_algebra_add** | `new_materials/linear_algebra_add` | Линейная алгебра: определители, Крамер, Гаусс, PCA, ковариация | 1 длинная страница + 6 визуализаций | нет (SVG) |
| 6 | **probability_add** | `new_materials/probability_add` | Теория вероятностей, комбинаторика, доверительные интервалы | 1 страница + 2 компонента | react-katex |
| 7 | **probability_tasks_add** | `new_materials/probability_tasks_add` | Задачи по комбинаторике и вероятности | 1 страница + 9 карточек-задач | katex (raw) |
| 8 | **statspark-analysis** ⭐ | `new_materials/statspark-analysis` | Математическая статистика (ANOVA, t-тесты, корреляция, факторный/кластерный анализ) | 1 большая страница + 3 визуализации | react-katex |

⭐ — **эталон дизайна** по заданию пользователя.

**Главный вывод:** содержательно проекты образуют единую логическую цепочку
**Функции → Пределы → Производные → Интегралы → Ряды → Дифф. уравнения → Линейная алгебра → Вероятность → Статистика**,
то есть это естественные разделы одного учебного портала по высшей математике. Технически они полностью совместимы (один стек), но различаются темами дизайна и движками рендера формул.

## 2. Поэлементный аудит проектов

### 2.1. `calculus-compass` (host, корень репозитория) — целевой проект

* **Назначение:** интерактивный курс начал анализа: что такое функция, типы функций, пределы, непрерывность, введение в производную.
* **Тема дизайна:** «Academic Indigo» — **светлая**, primary `210 50% 25%` (тёмно-синий), accent `38 85% 55%` (золото). Шрифты Crimson Pro + Inter.
* **Маршруты (`App.tsx`):**
  * `/` — главная (Index)
  * `/functions/{polynomial,rational,trigonometric,exponential,logarithmic,piecewise,absolute,special}` — 8 справочных страниц функций
  * `/module/{0..10}/...` — **38 структурированных уроков** (Module 0–10)
  * `/guide/:moduleId` — интерактивный гид
  * `/visualizations/{probability,integral}` — 2 визуализации
  * `*` — NotFound
* **Компоненты:** богатая инфраструктура уроков в `components/lesson/` — `Math`, `SEOHead`, `ScrollProgressBar`, `Breadcrumbs`, `LessonHeader`, `SectionNav`, `TldrBox`, `HeroCard`, `KeyFindingsGrid`, `CompleteButton`, `NextPrevLesson`, `RelatedMaterials`, `Quiz`. Это **наиболее развитая компонентная база** и она соответствует паттернам `CLAUDE.md`.
* **Прогресс/геймификация:** `lib/progress.ts` (localStorage).
* **Замечания:**
  * `index.html` содержит `<title>Lovable App</title>` и TODO-заглушки (SEO не настроен).
  * Содержит **дубликаты** `ConfidenceInterval.tsx` и `ProbabilityTheory.tsx` — побайтово идентичны версиям из `probability_add` (host уже частично «вобрал» проект 6).
  * `CLAUDE.md` (изменён, см. git status) описывает тему **«Neon Kinetic» (тёмная неоновая)**, которая **в коде не реализована** — фактический `index.css` светлый. → конфликт, см. §5.

### 2.5. `linear_algebra_add` — Линейная алгебра (визуализации)

* **Назначение:** одностраничник с интерактивными визуализациями линейной алгебры.
* **Маршруты:** `/`, `*` (весь контент в `pages/Index.tsx`, 524 строки).

* **Math-движок:** нет библиотеки — формулы свёрстаны в SVG/HTML.
* **Замечания:** пересекается с главами 5–8 проекта `_-_` (определители, собственные значения, PCA/SVD), но даёт **интерактивные визуализации**, которых нет в `_-_` на этом уровне. Пересекается с PCA/факторными нагрузками в `statspark`.

* **Math-движок:** react-katex.
* **Замечания:** **оба компонента побайтово идентичны** копиям в host (`src/components/ProbabilityTheory.tsx`, `ConfidenceInterval.tsx`). → прямой дубликат.

### 2.7. `probability_tasks_add` — Задачи по вероятности

* **Назначение:** разобранные задачи по комбинаторике и вероятности.
* **Маршруты:** `/`, `*` (Index, 372 строки).
* **Компоненты:** `ConceptCard`, `ProblemCard`, `MathFormula`, `InteractiveDiagram`.
* **Темы (карточки):** Классическое определение вероятности · Правило произведения · Перестановки · Размещения · Сочетания · Теоремы сложения и умножения · Формула полной вероятности · Формула Байеса. Множество задач с пошаговым решением и ответами.

* **Замечания:** **дополняет** `probability_add` (теория) практикой. Темы комбинаторики **пересекаются** с теоретическим блоком `probability_add`.

### 2.8. `statspark-analysis` ⭐ — Математическая статистика (эталон дизайна)

* **Назначение:** большой справочник по мат. статистике.
* **Тема дизайна (эталон):** **светлая**, `--background 210 100% 98%`, `--primary 217 91% 45%` (синий), `--accent 200 100% 50%` (голубой), `--shadow-elegant`, `--gradient-primary`, `--radius 0.75rem`. Карточки shadcn `Card` + `shadow-elegant`, табы, таблицы-«шпаргалки».

* **Содержание:** Однофакторный дисперсионный анализ (ANOVA) · проверка гипотез · F-статистика · суммы квадратов · t-тесты (пул., Welch, парный) · Манна–Уитни/Уилкоксон · Краскел–Уоллис · χ² · корреляции (Пирсон/Спирмен/Кендалл, Fisher z) · размеры эффектов · оценка объёма выборки · факторный анализ (EFA/CFA/PCA, KMO, Varimax) · кластерный анализ (k-means).
* **Компоненты:** `CorrelationMatrix` (heatmap), `CorrelationScatterPlots`, `HypothesisTestingDiagram`, `NavLink`.
* **Math-движок:** react-katex (KaTeX). ← совпадает с большинством.
* **Замечания:** наиболее «отполированный» визуально; берём его токены за основу единой темы.

## 4. Дубликаты и сильные пересечения

1. **Точный дубликат:** `probability_add/ProbabilityTheory.tsx` и `ConfidenceInterval.tsx` ≡ копии в host (`src/components/`). → при объединении оставить один экземпляр.
2. **Пределы / производные / интегралы** покрыты в 3–4 местах: host (введение, precalc), `strang-calculus-ru` (полная теория), `remix-of` (билеты-практика). → не дублировать: **host = интуиция/precalc**, **strang = полная теория**, **remix-of = практика/билеты** (перелинковать как разные слои одной темы).
3. **Ряд Тейлора / ряды:** `strang` (теория) + `remix-of` (билеты) + `_-_` (TaylorSeriesChart). → объединить в одну тему с тремя слоями.
4. **Линейная алгебра:** `_-_` (главы 5–8, теория) + `linear_algebra_add` (интерактивные визуализации). → визуализации `linear_algebra_add` встроить в соответствующие разделы курса `_-_`.
5. **PCA / факторный анализ:** `_-_` (7.2), `linear_algebra_add` (PCA-блок), `statspark` (factor analysis). → один концептуальный мост «линейная алгебра → статистика».
6. **Комбинаторика:** `probability_add` (теория) ↔ `probability_tasks_add` (задачи). → теория + практика одной темы.
7. **Доверительные интервалы:** host/`probability_add` (интерактив) ↔ `statspark` (контекст оценивания). → один компонент, перелинковка.

## 7. Предлагаемая стратегия объединения (high-level)

1. **Целевой проект — host (`calculus-visuals`)**: у него самая зрелая компонентная база уроков и `lib/progress`. Остальные 7 вливаем в него.
2. **Единая тема** — токены statspark (по §5.1, после подтверждения).
3. **Единый math-слой** — KaTeX/react-katex; конвертация MathJax.
4. **Единая иерархия разделов** (черновик, детализируется в `SITE_ARCHITECTURE.md`):
   1. Функции и графики (host)
   2. Пределы и непрерывность (host + strang + remix билеты)
   3. Производные и приложения (host + strang + remix)
   4. Интегралы (strang + remix + host-визуализация)
